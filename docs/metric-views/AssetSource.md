# AssetSource

`AssetSource` is a [Source](Source.md) of [metric views](MetricView.md#from) that can be a catalog table or view (even a metric view).

## Creating Instance

`AssetSource` takes the following to be created:

* <span id="name"> Name

`AssetSource` is created when:

* `Source` is [created](Source.md#apply) for a multi-part identifier (of a catalog table or view)
